# 생각하는 사람의 방

오귀스트 로댕의 청동 조각 「생각하는 사람」이 있는 밤의 전시실을 360도로 살펴보며 단서를 모으는 중학생용 3D 미술 방탈출입니다.

- 바로 해 보기: https://ngryun.github.io/rodin-thinker-room/
- 파일 하나(`index.html`)로 동작합니다. three.js(r160)는 jsDelivr에서, 글꼴은 Google Fonts에서 불러옵니다.
- 태블릿 가로 화면 기준 약 15~20분. 세로 화면과 데스크톱에서도 할 수 있어요.

## 조각상

조각상은 이미지나 3D 모델 파일 없이 코드로 빚습니다.

1. **골격**: 골반·척추·어깨·팔꿈치·손목·무릎·발목 관절을 실제 작품의 자세대로 배치합니다. 오른 팔꿈치는 왼 허벅지 위에 올리고, 상체는 왼쪽으로 비틀었습니다. 머리 위치는 말아 쥔 오른손 위에 턱이 얹히도록 손에서 역산합니다.
2. **근육과 세부**: 타원체·둥근 원뿔 350개를 부드럽게 합치고, 16개로 깎아 냅니다(SDF). 대흉근·광배근·척추세움근·어깨뼈·삼각근, 접힌 복직근, 대퇴사두근, 종아리, 손등 힘줄과 손가락 마디, 바위를 움켜쥔 발가락, 찌푸린 미간·벌름거리는 콧방울·다문 입술, 하나하나 배치한 머리카락 덩어리 등이 들어 있습니다.
3. **메시 변환**: 웹 워커 여러 개가 블록을 나눠 맡아 Surface Nets로 표면을 추출합니다(데스크톱 약 15만 정점). 시작 화면에 '조각을 주조하는 중' 진행 막대가 보이고, 끝나면 붉게 달군 청동이 식는 연출이 나옵니다.
4. **청동 재질**: SDF로 계산한 앰비언트 오클루전과 곡률을 바탕으로 파티나를 칠합니다. 움푹한 곳은 검은 갈색에 초록빛이 살짝 돌고, 볼록한 곳은 반질하게 닳은 금갈색입니다. 셰이더에서 로댕 특유의 손자국 질감을 범프로 더합니다.

## 단서와 정답

| 단서 | 하는 일 | 숫자 |
| --- | --- | --- |
| 1. 온몸으로 생각하기 | 로댕의 말("찌푸린 이마, 벌름거리는 콧구멍, 꽉 다문 입술, 팔·등·다리의 근육, 움켜쥔 주먹과 오므린 발가락")에 나오는 부분을 조각에서 찾아 누르기 | 8 |
| 2. 지옥의 문 | 뒷벽 「지옥의 문」 위의 작은 생각하는 사람(원래 이름 '시인')과 꼭대기의 망령들 찾기 | 3 |
| 3. 빛으로 읽기 | 조명 방향을 옆으로 돌려야 읽히는 받침대 명판 읽기 | 1880 |

마지막 자물쇠 정답: **8 · 3 · 1880**

- 탈출하면 '조각 감상하기'로 조명을 돌려 가며 조각을 볼 수 있습니다.
- 개발용 시험 훅은 주소 뒤에 `?debug`를 붙일 때만 켜집니다.
