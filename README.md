# 생각하는 사람의 방

오귀스트 로댕의 청동 조각 「생각하는 사람」이 있는 밤의 전시실을 360도로 살펴보며 단서를 모으는 중학생용 3D 미술 방탈출입니다.

- 바로 해 보기: https://ngryun.github.io/rodin-thinker-room/
- `index.html`과 조각 메시 `thinker.bin` 두 파일로 동작합니다. three.js(r160)는 jsDelivr에서, 글꼴은 Google Fonts에서 불러옵니다.
- `thinker.bin`을 불러올 수 없으면(예: `index.html`만 내려받아 바로 열 때) 조각을 코드로 빚어 대신 세웁니다.
- 태블릿 가로 화면 기준 약 15~20분. 세로 화면과 데스크톱에서도 할 수 있어요.

## 조각상

전시실의 조각은 「생각하는 사람」의 3D 모델(STL)을 바탕으로 합니다.

1. **변환**: `node tools/stl-to-thinker.mjs 원본.stl thinker.bin`이 진열용 둥근 받침을 떼어 내고, 게임 좌표(위 +y, 정면 +z)와 크기에 맞추고, 정점을 합칩니다. 정점마다 광선 64개를 쏘아 앰비언트 오클루전을 미리 구워 둡니다. 결과는 위치·삼각형·AO만 담은 약 470KB 바이너리입니다(정점 약 2.5만 개).
2. **불러오기**: 루프 세분화를 한 번 거쳐(삼각형 약 20만 개) 가까이 다가가도 면이 각져 보이지 않게 합니다. 바위는 스캔에 붙어 있어서 그 밑의 청동 받침판만 코드로 빚습니다. 지옥의 문 위 작은 '시인'은 세분화 전 메시를 씁니다.
3. **단서용 기준점**: 이마·코·입술·주먹·발가락 같은 부위와 어깨·팔꿈치·손목·엉덩이·무릎·발목 관절 위치를 스캔 표면에서 직접 재어 `SCAN_LM`에 적어 두었습니다. 조각을 누르면 이 기준점으로 어느 부위인지 판정합니다.
4. **청동 재질**: AO와 곡률을 바탕으로 파티나를 칠합니다. 움푹한 곳은 검은 갈색에 초록빛이 살짝 돌고, 볼록한 곳은 반질하게 닳은 금갈색입니다. 셰이더에서 로댕 특유의 손자국 질감을 범프로 더합니다. 시작할 때 붉게 달군 청동이 식는 연출이 나옵니다.

`thinker.bin`이 없을 때 쓰는 코드 조각은 타원체·둥근 원뿔 약 460개를 부드럽게 합치고 24개로 깎아 낸 SDF를 웹 워커 여러 개가 Surface Nets로 메시로 바꿉니다(데스크톱 약 25만 정점). 실제 작품 사진에 맞춰 어깨와 등 윗부분을 머리 높이 가까이 올렸고, 견갑골·척추 고랑·눈꺼풀·곱슬머리까지 빚었습니다.
